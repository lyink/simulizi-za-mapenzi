## 🎨 Change Theme Settings

### Font Size:
1. Open drawer (swipe right)
2. Tap "Font Size"
3. Select: Small, Medium, Large, or Extra Large
4. Tap "Apply"
5. **All text changes immediately!**

### Color Scheme:
1. Open drawer
2. Tap "Color Scheme"
3. Select: Default (Brown), Blue, Green, or Purple
4. Tap "Apply"
5. **AppBar and buttons change color!**

### Dark Mode:
1. Open drawer
2. Toggle "Dark Mode" switch
3. **Everything becomes dark theme!**

## 📚 Import Stories with Chapters

### Admin Panel:
1. Open drawer → "Admin Panel"
2. Tap "Import Stories from JSON"

### JSON Format:
```json
[
  {
    "title": "My Story - Part 1",
    "author": "Author Name",
    "category": "Romance",
    "coverImageUrl": "https://your-image-url.jpg",
    "synopsis": "Story description",
    "readingTimeMinutes": 15,
    "chapters": [
      {
        "number": 1,
        "title": "Chapter 1",
        "verses": [
          {"number": 1, "text": "First paragraph..."},
          {"number": 2, "text": "Second paragraph..."}
        ]
      },
      {
        "number": 2,
        "title": "Chapter 2 - Continuation",
        "verses": [
          {"number": 1, "text": "Story continues..."}
        ]
      }
    ]
  }
]
```

### Import:
1. Paste JSON or pick file
2. Click "Preview"
3. Verify chapters
4. Click "Import"
5. Done!
